## 二、逐任务：目标 / 输入 / 输出 / 依赖 / 验收

### T0 文档对齐与废弃清理 ⚠️ 需授权
- **目标**：让文档与代码一致，移除 Tauri/React 时代产物
- **输入**：你的删除授权 + 备份目录确认
- **输出**：`_backup/` 备份；删除 `package.json`/`web/`/`src-tauri/`/`backend/launcher.py`；`README.md` 重写为 PySide6 流程
- **依赖**：无 ｜ **可并行**：是（任何时候都能做）
- **验收**：`README.md` 中的启动命令可原样复制执行成功；删除项在项目内不再存在

### T1 V1 骨架 + V0→V1 跳转
- **目标**：让"仍以演示模式进入"和"全绿自动跳转"真正生效
- **输入**：无（后端在线即可）
- **输出**：`desktop/views/main_view.py`；`window.py` 注册双视图；`app.py` 接线
- **依赖**：无
- **验收**：程序化断言——点击后 `stack.currentWidget().objectName() == 'mainView'`

### T2 会话区
- **目标**：列出会话、可点选、可刷新、有空态
- **输入**：`GET /api/sessions`（真实返回 4 条）
- **输出**：`listSessions` 渲染 `name` + 红点（`isnew`）+ tooltip（`time`/`content`）
- **依赖**：T1
- **验收**：项数 = 接口返回条数；选中项名字与接口一致；接口返回空数组时显示"暂无会话"而非空白

### T3 消息区
- **目标**：按类型渲染消息，三态齐全
- **输入**：`GET /api/messages?who=张三&limit=60`（真实返回 5 条）
- **输出**：气泡（`friend` 左 / `self` 右 / `sys·time·recall` 居中灰字）
- **依赖**：T1
- **验收**：气泡条数 = 接口条数；`self` 靠右；切会话后旧消息被清空；空列表显示"暂无消息"

### T4 回复区（核心闭环）
- **目标**：生成 → 改 → 填入 → 发送
- **输入**：`POST /api/reply`、`/api/fill`、`/api/send`
- **输出**：`inputInstruction`/`btnGenerate`/`editReply`/`lblSource`/`btnFill`/`btnSend`
- **依赖**：T1
- **验收**：生成的文本 = 接口 `data.reply`；点发送后 800ms 刷新，列表中出现该条 `self` 消息；请求中按钮为 disabled

### T5 开关 + WS
- **目标**：贴边/监听可控，新消息自动出现
- **输入**：`POST /api/dock`、`/api/listen`、`GET /api/status`、`WS /ws/messages`
- **输出**：`btnDock`、`btnListen`、WS 客户端（**用 PySide6 自带 `QWebSocket`，不新增依赖**）
- **依赖**：T1
- **验收**：开关状态与 `status` 返回的 `docking`/`listen` 一致；监听关闭时 WS 不连

### T6 Toast + 错误码收口
- **目标**：所有失败都有人话提示，绝不显示堆栈
- **输入**：PRD §5 错误码表
- **输出**：`toast()` 统一方法 + `code→文案` 映射
- **依赖**：T2–T5
- **验收**：逐个触发 1000/1001/2001/3001/4001/5000/网络异常，文案与颜色符合映射表，且不弹 `QMessageBox`

### T7 修复重复发送 ⚠️ 部分需授权
- **目标**：连点两次发送只发一次
- **输入**：前端防抖（T4 已含）+ 后端 3 秒幂等（**需先改 `CLAUDE.md §4`**）
- **输出**：`send`/`fill` 加幂等键；`CLAUDE.md §4` 增加说明
- **依赖**：T4 + 你的授权
- **验收**：`_verify_e2e.py boundary` 中 B7 从 FAIL 转 PASS（第二次返回 `code=0` 但后端实际未重复执行）
- **降级方案**：若你不授权改规范，只做前端防抖 → B7 仍标记为"前端已防抖，后端无幂等"

### T8 V1 完整验证

- **输入**：运行中的后端
- **输出**：PASS/FAIL 矩阵 + 三张截图（成功 / 空态 / 错误态）存入 `docs/screenshots/`
- **依赖**：T2–T7
- **验收**：V1 全部断言 PASS；三张截图均能看清内容且与预期状态一致

### T9 README 重写

- **验收**：按 README 的步骤从零启动能跑起来

### T10 V2/V3（可选）⚠️ 需决策
