## 2. 边界验证

| # | 场景 | 预期 | 实际结果 | 状态 |
|---|---|---|---|---|
| B1 | 空输入：未选会话 `POST /api/reply {}` | `2001` | `code=2001 message=未选择会话` | ✅ |
| B2 | 空输入：`text=""` | `4001` | `code=4001 message=text 不能为空` | ✅ |
| B3 | 空输入：纯空格 `"   "` | `4001` | `code=4001`（已 strip 校验） | ✅ |
| B4 | 超长输入：发送 5000 字 | 不崩、不截断 | HTTP 200，`ok=True`，0.02s | ✅ |
| B5 | 超长输入：`instruction` 5000 字 | `code=0` 且返回回复 | `code=0 source=rule`，0.01s | ✅ |
| B6 | 越界：`limit=9999` | 被拦截或钳制 | **HTTP 422**（FastAPI `le=200` 校验） | ✅ |
| B7 | 重复操作：连点两次发送 | 第二次应被拦截 | **两次都 `ok=True`** —— 后端无幂等保护 | ❌ **需修复** |
| B8 | 访问不存在的路径 | 404 且无堆栈 | HTTP 404 | ✅ |
| — | 后端不可用（杀掉 8765 进程） | 友好提示、不白屏 | UI 显示：**“后端未启动 / 后端未连接（http://127.0.0.1:8765）”**，隐藏“演示模式进入”按钮 | ✅ |

**B7 说明**：后端每次调用都真实执行一次发送，重复点击会**真的发两条**。修复只能靠前端防抖（PRD §3.6 已要求：请求中禁用按钮），
但 V1 未实现，所以该风险**当前无法闭环**。另建议后端加一个 3 秒内相同 `{who,text}` 的幂等去重（需先写入 `CLAUDE.md §4`）。
