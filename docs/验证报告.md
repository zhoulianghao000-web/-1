## 6. QQ 能否替代微信做完整验证 —— 结论：不能

```
QQ NT 9.9.31.49919   C:\Program Files\Tencent\QQNT\QQ.exe
UIA 子树元素总数 = 2（窗口自身 + 1 个无名元素）
子窗口数量      = 1（'Intermediate D3D Window'）
```
QQ NT 内容全部由 D3D 渲染，**没有可读取的控件树**：

| 能力 | 结论 |
|---|---|
| 读会话列表 / 消息文本 | ❌ 读不到（无 MSAA/UIA 文本） |
| 填入 / 发送并验证结果 | ❌ 只能剪贴板+Ctrl+V，会抢焦点且无法确认 |
| **贴边跟随 / 窗口存在与位置** | ✅ 只用窗口 rect，win32 足够（已验证 PASS） |

> 顺带印证：微信 4.x 与 QQ NT 同属 Chromium/D3D 渲染，所以 4.x Adapter 必须换采集方式（UIA + 坐标/图像兜底），不能沿用 wxauto 的控件+像素高度思路。
